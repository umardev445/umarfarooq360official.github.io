Un intervalo estima una media, no la mayoría de los valores

Un intervalo de confianza para una media intenta describir la incertidumbre de una estimación poblacional a partir de una muestra. No es el rango mínimo–máximo observado ni el intervalo en el que caerá el 95 % de las personas. Empieza identificando qué población, variable y unidad quieres estudiar, cómo se recogieron los datos y si las observaciones pueden tratarse como independientes.

El procedimiento bilateral t que se presenta aquí se utiliza cuando se estima la media con una desviación poblacional desconocida a partir de la desviación muestral s. El modelo clásico se apoya en observaciones independientes de una población normal; aproximaciones con muestras mayores necesitan valorar asimetría, valores extremos y diseño. El tamaño por sí solo no corrige una muestra sesgada ni datos repetidos tratados como independientes.

Distingue desviación, error estándar y margen

La fórmula es media muestral ± t crítico × s/raíz(n). El término s/raíz(n) es el error estándar estimado de la media. El cuantil t depende del nivel de confianza bilateral y de n−1 grados de libertad. Un IC del 95 % usa el cuantil 0,975 de esa distribución, no 0,95. Necesitas al menos dos observaciones para calcular s con divisor n−1.

La desviación s describe dispersión de observaciones; el error estándar describe la escala estimada de variación de la media entre muestras bajo el modelo. Confundir ambos produce márgenes diferentes. Conserva más precisión durante el cálculo y redondea los límites solo al presentar el resultado.

Ejemplo original: media 100, s 10 y n 25

Supón una muestra ficticia de 25 mediciones independientes con media 100 y desviación muestral 10. Para un IC bilateral del 95 %, los grados de libertad son 24 y t crítico es aproximadamente 2,0639. El error estándar vale 10/raíz(25) = 2. El margen es 2,0639 × 2 = 4,1278. El intervalo redondeado es 95,87 a 104,13 unidades.

Puedes comprobar el cuantil en R con qt(0.975, df=24). Después calcula 100 + c(-1,1)*qt(0.975,24)*10/sqrt(25). No necesitas convertir el resultado en una proporción ni declarar que cada medición está dentro de esos límites. Son límites para la media que estima el método.

Compara el ancho sin prometer un resultado futuro

Como ejercicio de sensibilidad, conserva artificialmente media 100 y s 10 y cambia n a 100. Con 99 grados de libertad, t crítico es aproximadamente 1,9842; el error estándar sería 1 y el intervalo, 98,02 a 101,98. Es más estrecho. Este cálculo mantiene constantes dos cifras para aislar el efecto del tamaño; una nueva muestra real puede tener otra media y otra desviación.

Aumentar la confianza también cambia la amplitud si todo lo demás se mantiene. Más confianza exige un margen mayor con este método. Decide el nivel antes de interpretar el resultado; no pruebes niveles hasta que el intervalo excluya el valor que no te conviene. Anota cualquier análisis exploratorio como tal.

Qué significa el 95 % en este procedimiento

El 95 % describe el comportamiento del método en muestreo repetido bajo sus condiciones. Si se repitiera el procedimiento muchas veces, aproximadamente el 95 % de los intervalos así construidos cubriría la media fija de la población. Una vez calculado un intervalo concreto, no se expresa como una probabilidad del 95 % de que ese parámetro fijo esté dentro. Esta es la distinción explicada por NIST.

Tampoco indica que tengas el 95 % de los datos ni una probabilidad individual de éxito. Cuando comuniques el resultado, identifica que se trata de un intervalo bilateral para la media y adjunta la unidad. Un límite numérico sin población, muestra o método no permite evaluar qué estás estimando.

Comprueba qué observaciones son independientes

Veinticinco mediciones de una misma persona no son necesariamente equivalentes a 25 personas independientes. Varios alumnos de una misma clase pueden compartir condiciones relevantes. Si el diseño incluye grupos, medidas repetidas, pesos o selección compleja, el error estándar simple puede ser inadecuado. Describe el diseño y utiliza el procedimiento que le corresponda.

Caso ficticio de sesgo: preguntar voluntariamente a quienes salieron satisfechos de un servicio puede dejar fuera a otros usuarios. Un intervalo estrecho calculado con esas respuestas no demuestra que represente a todos. Antes de añadir decimales, revisa el mecanismo de selección y qué población puedes describir con honestidad.

Preguntas frecuentes

¿Puedo sustituir s por el rango?

No. La fórmula usa la desviación estándar muestral, no la diferencia entre máximo y mínimo.

¿El 95 % de las personas está dentro del intervalo?

No. Este intervalo estima la media; describir observaciones individuales requiere otra pregunta y procedimiento.

¿Una muestra grande elimina el sesgo?

No. Más observaciones no corrigen automáticamente la selección ni la dependencia entre datos.
