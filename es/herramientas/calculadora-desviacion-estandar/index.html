Calculadora de desviación estándar: muestra y población

Calcula desviación estándar, varianza y media con tus datos. Elige muestra o población, revisa la suma de cuadrados y comprende cada paso del cálculo.

Calcula la dispersión de tus datos

Ejemplo editable: 2; 4; 4; 4; 5; 5; 7; 9. Elige población o muestra y revisa los pasos.

Hasta 1.000 datos. Con coma decimal usa punto y coma o saltos de línea entre valores.

El cálculo del ejemplo aparecerá al cargar la herramienta.

Los datos del formulario se calculan en tu navegador. Nuestra medición de interacción no incluye notas, nombres de asignaturas ni cifras introducidas. Consulta la privacidad.

Respuesta rápida. La desviación estándar mide la dispersión en las unidades originales. Selecciona población para dividir entre n o muestra para dividir entre n − 1; una muestra necesita al menos dos datos.

Cómo introducir los datos sin cambiar su significado

Pega una lista de números y elige el tipo de separador. Con punto decimal puedes usar espacios, comas, punto y coma o saltos de línea entre valores. Con coma decimal, separa los valores mediante punto y coma o líneas: escribe 1,5; 2,5; 3,5.

No utilices separadores de miles ni mezcles unidades en una misma lista. Una celda vacía, una palabra o un número mal formado debe corregirse; no se convierte silenciosamente en cero. La herramienta admite hasta 1.000 observaciones para mantener el detalle legible.

Población o muestra: elige por la pregunta

Elige población cuando describes todo el conjunto definido para tu análisis. Elige muestra cuando usas observaciones para estimar la dispersión de una población más amplia. El tamaño pequeño o grande de la lista, por sí solo, no decide la opción.

Con una sola observación, la dispersión poblacional es cero, pero la desviación muestral no está definida porque n − 1 sería cero. Con valores idénticos y al menos dos observaciones, ambas desviaciones son cero.

Ejemplo completo: 2, 4, 4, 4, 5, 5, 7 y 9

La suma es 40 y hay 8 observaciones, así que la media es 5. Las diferencias respecto a la media son −3, −1, −1, −1, 0, 0, 2 y 4; sus cuadrados suman 32.

Para población, la varianza es 32 ÷ 8 = 4 y la desviación estándar es √4 = 2. Para muestra, la varianza es 32 ÷ 7 ≈ 4,571429 y la desviación es aproximadamente 2,138090. La diferencia proviene del divisor, no de otros datos.

Qué significa el resultado

La media y la desviación deben leerse juntas. Dos conjuntos pueden tener una media idéntica y distinta dispersión. La desviación se expresa en la misma unidad que los datos; la varianza utiliza la unidad al cuadrado.

Una desviación alta o baja solo tiene sentido en relación con el contexto y la escala. No significa automáticamente que un examen fue bueno, que un dato es erróneo o que una persona tiene un problema. Esta herramienta no realiza diagnósticos ni pruebas de hipótesis.

Datos agrupados, pesos y redondeo

Esta versión calcula una lista de observaciones individuales con el mismo peso. No interpreta automáticamente una tabla de intervalos ni una columna de frecuencias. Si tu ejercicio tiene frecuencias o pesos, aplica el modelo correspondiente en lugar de pegar las dos columnas como si fueran observaciones.

El cálculo conserva la precisión interna y redondea la presentación. La tabla de detalle muestra las primeras 30 observaciones si la lista es extensa; los totales incluyen todos los datos válidos. Revisa el número de observaciones para detectar valores omitidos o duplicados.

Del cálculo a la explicación

Consulta la guía de desviación estándar para entender el método. Si necesitas un archivo de trabajo, sigue el ejemplo en Excel.

La desviación media absoluta responde a otra fórmula: no es un sinónimo. Tus datos se procesan localmente en el navegador y esta herramienta no los envía a AspireCompass.

Preguntas frecuentes

¿Por qué muestra y población dan resultados distintos?

La fórmula muestral divide entre n − 1; la poblacional divide entre n. Elige el modelo según el conjunto que quieres describir.

¿Puedo usar coma decimal?

Sí. Selecciona coma decimal y separa los números con punto y coma o saltos de línea. No uses separadores de miles.

¿Se guardan mis observaciones en un servidor?

Esta herramienta realiza el cálculo en tu navegador. No envía la lista de datos como parte del cálculo.
