The short answer

Under replacement, remove the old quality points and add the new points while retaining the same GPA-credit denominator for an equal-credit repeat. If both attempts count, add the new attempt's points and credits without removing the old attempt.

Next step: Use current GPA-counted credits that already include the old attempt. Enter each old attempt once and confirm the repeat rule before relying on either result.

Two policies, two calculations

Current quality points are current GPA multiplied by GPA-counted credits, unless you enter exact transcript quality points. For each course, old and new points are its credits multiplied by the respective grade points. This tool assumes that the repeat carries the same credits as the old attempt.

Worked example: retaking a three-credit F

A 2.60 GPA across 45 counted credits gives 117 quality points. The old three-credit F contributes zero. A new A worth 4.0 contributes 12. With replacement, 129 ÷ 45 = 2.87. With both attempts, 129 ÷ 48 = 2.69. The same new grade therefore has different effects.

Worked example

Using 45 − 3 credits with the unchanged 2.60 GPA would imply 109.2 starting points, which is not the actual record after excluding a zero-point F. If you adjust a record manually, remove both the appropriate quality points and credits before recomputing the GPA.

Use the correct transcript totals

Earned credits, attempted credits and GPA-counted credits can differ. A pass/fail course may earn credit without entering GPA, while a failed attempt can enter GPA without earning degree credit. Read the transcript labels or ask the registrar which totals to use.

A rounded displayed GPA is an approximation to its underlying quality points. The optional exact-quality-points input lets you use the transcript numerator directly. If the old attempts cannot mathematically fit the record, the tool asks you to check the inputs rather than showing an impossible average.

Why your institution may produce a different official result

Institutions can limit repeat eligibility, restrict the number of repeat credits, keep both attempts on a transcript or apply exceptions based on timing. The University of Maryland's published repeat guidance is an example of a policy that needs more information than one generic formula. It is not a rule for all colleges.

Do not confuse removing a grade from the GPA calculation with deleting the historical attempt from the transcript. Also check scholarship or financial-aid rules separately; this calculator does not determine eligibility for either.

A lower retake grade can lower the result

If the new grade is below the old grade, the replacement model can reduce GPA. Some institutions instead use the higher grade or apply other restrictions, but that is a third policy question and is not automatically selected here.

Compare the realistic grade improvement, repeat approval and credit load before registering. When the goal is a target cumulative GPA across new courses, use the existing target planner rather than entering unrelated new courses as if they were repeats.

Frequently asked questions

Do retakes always replace the old grade?+

No. Repeat treatment depends on the institution and your eligibility. This tool compares two models without choosing the official policy.

Do I enter the old course in my current totals?+

Yes. The current GPA and credits should already include it. The tool performs the removal for the replacement scenario.

Why are my two results different?+

Replacement changes the old points while keeping the equal-credit denominator. Counting both attempts adds another attempt's credits as well as its points.

Can I use a course repeated for a different number of credits?+

Not in this simplified equal-credit model. Ask the registrar for the appropriate treatment before recalculating the record.
